# reflection: intent-alignment before action (the learning invariant's wear-in)

**Provenance:** Operator-proposed 2026-07-07, dyadically converged same day;
codified as DYAD.md operating-policy #5, third invariant. This is the
invariant's wear-in record — a real breach, caught by the Operator, converted
to rule (the anchor's own standard: values/invariants wear in at the first
real breach, honestly marked).

## What happened (the evidence)

During the substrate bootstrap session (2026-07-07), the Agent repeatedly
acted on its own interpretation of fresh directives without first presenting
that interpretation, forcing Operator falsification at the artifact stage and
Agent backtracking:

1. **Committed `WORKSTREAMS.md` ledger** on interpreting "the DAG had been the
   preferred mechanism" — the Operator then had to direct "minimum … pointers
   to node details on GitHub Issues", then "generated on the fly": the file
   was deleted two commits after it was created.
2. **Encoded node status as body text** on interpreting "leverage GitHub
   Issues" — the Operator then had to ask "are you implementing status as
   gh-issue tags?" and supply the collision requirement: all 11 node bodies
   were edited and the state model migrated to labels.

Each round was Generate→Validate working — but at the expensive stage.
Falsification of an interpretation costs words; falsification of artifacts
built on it costs rework and history noise.

## The rule it forged

**Sense closes only by Operator confirmation** (DYAD.md #5, third invariant):
a new or redirected intent opens SPAOR's Sense turns — Agent plays back
interpreted intent + entailed invariants + design elections; Operator's
confirmation closes Sense; Plan/Act follow. Within an aligned scope,
reversible on-branch acts proceed; an unstated design election reopens Sense.
Grounded in G0's `no-self-ratify`: acting on unratified interpretation is the
proposer ratifying its own proposal.

Vocabulary note: the loop is codified with the form's canonical token —
Sense · **Plan** · Act · Observe · Reflect (Operator ruled against a local
"Probe" variant, 2026-07-07).

## Calibration (what the rule does NOT demand)

Not zero falsification rounds — friction is the mechanism, and value/invariant
materialize through practice. The rule moves falsification to the cheap stage;
it must not invert into ask-before-every-act, which would break wu-wei and
push proposing toward permission-seeking.

## Curriculum tie (WS6 source)

A module: the learner-agent receives a deliberately underspecified directive
and must produce the intent/invariant playback and elicit before acting.
Verification a "taught" claim cites: directive completed with zero backtracked
artifacts; learner-Operator confirms the interpretation matched. This
session's misses become anonymized rep material — converted to reps, never
narrated (the fixed constraint: the coach never learns for the learner).
