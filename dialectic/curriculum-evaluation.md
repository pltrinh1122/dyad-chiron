## 1. Why this skill is load-bearing

`no-self-ratify` forbids chiron certifying its own curricula; ratification by
Operator merge is the **only certificate** a chiron curriculum can earn before
real graduation. A certificate signed by a novice evaluator is conferral
wearing ratification's costume — the invariant is only as strong as the
ratifier's competence. So this L1 skill is not an elective: it is the other
half of the dyad's certification loop. (Noted for the record: the Operator
surfacing their own novice status is an axis-D self-application in the wild —
falsifying the premise *"my Lesson-0 verdict will be well-grounded."*)

## 3. Skill decomposition — form ⟂ content ⟂ economy

| axis | what the evaluator checks | failure it guards |
|---|---|---|
| **Form** (domain-general) | constructive alignment (objective ↔ practice ↔ assessment name the *same* skill) · rep-vs-exposition discrimination · progression soundness (prereqs, ramp) · assessment validity, reliability, **earnability** · gates that evidence could actually fail | a beautiful document that teaches nothing; unfalsifiable gates; scores no learner could recompute |
| **Content** (per-curriculum domain) | decomposition completeness (are these the real sub-skills and failure modes) · terminal-state fitness (is graduation the right target) · material authenticity (ecological reps vs. toy reps) | training the wrong skill well |
| **Economy** | telos fit — learning-turns budgeted against the skill's value · adaptivity (placement, earned skipping) | a sound curriculum nobody can afford to run |

## 4. Rep formats

- **E-R1 — seeded-defect review (sealed key).** The coach authors or mutates
  a curriculum specimen with k planted defects — an exposition step disguised
  as a rep · a score no learner could recompute · a gate no evidence could
  fail · an assessment measuring a different skill than its objective. Key
  hash-sealed pre-rep (the R1 machinery, reused). Detection scored
  mechanically.
- **E-R2 — rubric distillation (r1: practice-first).** After each live
  falsification pass on a curriculum specimen, the learner distills what the
  pass proved into rubric criteria: every refutation that forced a revision
  names a property the artifact lacked; every grounded survival names one it
  held. **Each criterion cites the pass that earned it** — the rubric grows
  only from lived practice, never from pre-derived theory (the dyad's
  falsify→codify loop, pointed at curriculum evaluation). The rubric is the
  track's **living artifact**: versioned, Operator-owned, never coach-edited.
  Late-stage counterpart — **frameworks attack**: once rubric v≥1 exists, the
  learner self-selects external instructional-design references and uses them
  to falsify the rubric (which real criterion is still missing?); the diff is
  scored: missed criterion · overweighted · novel-and-defensible. The coach
  never explains the frameworks — the learner reads, the diff is the rep.
- **E-R3 — live evaluation.** Every real chiron proposal is a specimen (this
  document and `falsification-curriculum.md` are the first two). Ground
  truth arrives downstream: a defect the evaluation missed that later costs
  learner-turns is a scored miss. Slow but ecological — the terminal
  instrument.
- **E-R4 — revision prediction.** After evaluating a live specimen, predict
  which parts the dialectic will force to revise, with confidence; scored at
  dialectic close. Calibration, for evaluators.

Seeding honesty rule inherited unchanged from the falsification track: seeds
live only in labeled rep material, never in durable dyad artifacts.

## 5. Learning path

The path is one practice spine (r1): the falsification track supplies every
early rep; this track adds only the distillation move.

- **E0 — baseline + rubric v0 (this session, shared with Lesson 0).** The
  falsification pass on `falsification-curriculum.md` doubles as this track's
  baseline: after verdicts, the critique's coverage is classified against
  §3's axes — which evaluation criteria the Operator already wields, which
  are absent. Then the first E-R2 distillation: **rubric v0 is born from that
  same pass.** One rep, two scorecards and a rubric; zero extra
  learning-turns.
- **E1 — iterate on live specimens (E-R3 + E-R2).** Every curriculum
  artifact that exists anyway gets the same treatment: falsification pass →
  distillation (the Lesson-1 sheet, each proposal revision, the dyad-setup
  v0 when #8 unblocks). Gate: rubric v≥2 in which every criterion cites the
  pass that earned it, spanning at least two of §3's three axes.
- **E2 — seeded specimens (E-R1).** Once an earned rubric exists, the coach
  seeds specimens: defects the rubric should catch (does it work?), plus
  defects it cannot yet name (forcing growth) — form seeds first, then
  content seeds (a wrong decomposition, a mis-targeted terminal state, toy
  reps passing as ecological). Gate: detection at threshold on 2 consecutive
  specimens, including ≥1 rubric-extending find.
- **E3 — rubric falsification + calibration.** The frameworks attack (E-R2
  late stage) + standing E-R4 revision predictions on live proposals. Gate:
  revision-prediction calibration within bound; missed-defect cost trending
  down.
- **Graduation.** Two conditions, both earned: (a) the rubric is **stable** —
  two consecutive new specimens force no rubric revision; (b) an evaluation
  of a curriculum **chiron did not author** (external or another dyad's)
  stands up — its defect-list survives the falsification method applied back
  to it. Thresholds elected, not yet worn. Per the shared claim-strength
  ladder (r2; `falsification-curriculum.md` §5): this certifies **readiness
  to ratify**, not evaluator mastery — mastery is shown only by the
  post-graduation ratification record: curricula ratified with this skill
  holding up under real learner use.

## 6. The sharpened conflict-of-interest, named

The falsification track named a coach⟂agent conflation; this one is sharper:
**the evaluated party authors the evaluator's training.** Mitigations: E-R2
grounds the rubric in the anchor and external frameworks, independent of the
coach; E-R1 keys are hash-sealed pre-rep; E-R3's ground truth is reality, not
the coach's grading; and the rubric is the Operator's — the coach never edits
it, only seeds specimens against it. Residual risk stays named rather than
hidden: the coach chooses the seeds, so the coach chooses what "defect" means
in training material. The external-specimen graduation condition (§5) is the
designed escape from that loop.

## 7. Interlock with the falsification track (#61)

**Method ⟂ rubric, one practice spine (r1).** Falsification supplies the
method — cheap severe probes, honest verdicts — and, per the Operator's
mental model, it also supplies the *practice vehicle*: this track's early
reps ARE falsification passes on curriculum artifacts, plus one added move
(distill the pass into rubric criteria). The tracks diverge only late (seeded
specimens, frameworks attack). Their product is **sound ratification**: the
dyad's certification loop closed by competence on both halves. Shared reps
wherever telos allows (Lesson 0 = E0); separate scorecards always.
