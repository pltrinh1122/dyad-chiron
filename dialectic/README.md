# dialectic/ — live contests

Per the ontology (DYAD.md #7), `dialectic/` is the home for **live contests**:
open questions held under stress-test. A record lives here only while its question
is still contested; when the question **earns its answer** it moves to `reflect/`
(the settled Reflect output).

gap — the dir persists so the next contest has a home. Its first and (so far) only

settled parts codified into `DYAD.md` #4 (channel discipline) and #5 (concurrency/
WIP, proactivity/autonomy-boundary).
